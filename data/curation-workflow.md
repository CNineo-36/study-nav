# 持续筛选高中课程

目标：补齐学生当前需要的考点，并在已有课程中保留更适合学生的版本。新视频进入候选池，不因老师知名或发布时间新而直接上线。

## 候选来源

以现有官方作者为起点，通过固定作者 UID 跟踪其投稿、课程合集新增内容及多P分集变动。化学优先一化儿和化学超人，数学一数，语文学过石油的语文老师，生物一生儿和汉水丑生，地理一地er；其他作者名单按现有资源逐个确认官方身份。避免同名搬运号、课程转载号和引流号。

每轮检查记录上次成功检查时间，新视频按 BVID 去重，多P按 CID 去重。保留候选的作者、官方标题、发布日期、链接、分集、时长、考点和筛选结论。多P新小节属于老投稿更新，不能只看投稿发布日期。

## 入选门槛

必须适用于高中课程或高考，直达公开视频或具体分集。排除无实质讲解的预告、纯广告、重复转载、非高中课和只引导付费获取完整内容的片段。课程较长时如实标明，不能把专题串讲包装成短时单考点。

## 与旧资源比较

按“学科 + 考点 + 适用阶段 + 难度”比较。优先补未覆盖考点；同一考点保留用途不同的基础讲解和题型练习。如果新旧用途相同，应明确新课是否在结构、先修要求、例题、纠错或教材更新上有改进。不能仅凭标题、播放量、点赞或发布时间认定更好。

页面信息与目录可以支持初筛。教学质量判断需要查看实际讲解、配套材料或可核对的字幕，并抽查关键定义、步骤、例题和答案；有疑点的内容保留在候选池。无法取得实际内容时，只标“元数据已核对”，不标“教学质量审核通过”。热门程度和评论仅作辅助信号，评论中的具体错误需独立核实。

## 决定与维护

候选结论为“新增、与旧课互补、待进一步审看、暂不收录”。每次只上线少量有明确用途的课程，记录一句可核查的收录理由及检查范围。质量证据不足时可以零新增。

失效资源和明显过时课程进入修复队列。替换旧课时保留旧 URL 到新 URL 的迁移记录，以免丢失收藏；在收藏兼容处理完成前，避免直接删除收藏目标。教师调整多P顺序时，按 CID 找回正确分P并更新链接。

## 运行方式

网站目前为 GitHub Pages 静态页面，持续检查须由本地定期任务或另行配置的服务执行。此文档是筛选流程，不代表已创建自动任务。频率和自动发布规则应先明确；可先自动发现候选，再经实际内容核查后提交与发布。
